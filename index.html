06 — FAQ

常见问题 Questions People Ask

// 关于用 AI 做产品 // about building with AI
我完全不懂编程，可以做出来吗？ I know nothing about coding. Can I still build something? +

可以，但要做对两件事。一是把目标压到足够小——不是"做个电商平台"，而是"帮我把客户的报价单转成表格"。二是接受第一版很粗糙：我做的第一个产品丑得我自己都不想截图，但我们用上了三个月。 Yes, as long as you do two things right. Shrink the target until it's small — not "build an e-commerce platform" but "turn my client's quote into a table". And accept that v1 is rough: my first product was so ugly I didn't want to screenshot it, but we used it for three months.

如果完全不想碰代码，AI 编程工具也能让你只用对话完成大部分工作；如果你想学得更扎实，那就走一遍"自己写一遍"的流程，收获会大得多。 If you'd rather not touch code at all, AI coding tools let you do most of it through conversation. If you want to actually learn, do one pass of writing it yourself — the payoff is much larger.

这件事大概要花多少钱？ How much will this cost me? +

认真做第一个产品的话：0-300 元。订阅一个 AI 编程工具（月费 20-100 元），域名约 60 元/年，静态托管很多平台有免费额度，加起来第一个月基本零成本。 To build your first product seriously: 0-300 CNY. One AI coding subscription (20-100/month), a domain (~60/year), and free tiers for static hosting cover most of it.

真正的大头是时间，不是钱。据我的经验，一个能上线的小产品需要 20-40 小时。值得注意的是：产品有真实用户之后，AI 调用的月度成本可能超过订阅费，所以定价时要把这一项算进去。 The real cost is time, not money: roughly 20-40 hours for a shippable small product. One thing people forget — once you have real users, monthly AI API costs can exceed the subscription fee, so factor that into pricing.

用 AI 写的代码能商用吗？ Can I use AI-generated code commercially? +

多数主流工具（Claude Code、Cursor、Copilot）的用户协议都允许商用产出，但你仍然要为代码负责：许可证归属在部分地区尚无明确判例，尤其是用于对外交付的软件项目。 Most major tools (Claude Code, Cursor, Copilot) allow commercial use of their output, but you're still responsible for the code: license ownership has no clear precedent in some jurisdictions, especially for software you deliver to clients.

我的做法是：自己上线的小工具直接用；给客户交付的项目会去掉任何从网上复制的片段，并说明实现方式。金额较大的商业项目，建议先问一句律师。 My approach: use it directly for my own small tools; for client projects I strip anything copied from the internet and explain how it's implemented. For high-value commercial work, talk to a lawyer first.

学多久能做出第一个产品？ How long until I can ship my first product? +

如果你每天投入 2 小时，2-4 周能做出一个粗糙但真实可用的产品。我身边最快的案例是 9 天，最慢的用了 3 个月——差别主要不在技术，而在"需求有没有想清楚"。 At 2 hours a day, 2-4 weeks gets you a rough but genuinely usable product. The fastest case I know took 9 days, the slowest took 3 months — the difference was never technical, it was whether the requirement was clear.

我写了一篇更完整的 90 天版本，包含了每周的里程碑和最容易踩的 5 个坑。 I wrote a fuller 90-day version with weekly milestones and the 5 traps that catch people most often.

我应该先学哪个工具？ Which tool should I learn first? +

先学对话，不是编辑器。选一个你能天天用的对话模型（Claude 或 ChatGPT 均可），把它用熟——这是所有效率提升的地基。等你发现"跟它聊天已经不够用了"，再学 Cursor 或 Claude Code 这类 AI 编程工具，这时候你才知道该教它什么。 Start with conversation, not an editor. Pick one chat model you can use daily (Claude or ChatGPT) and get good at it — that's the foundation of everything else. Move to tools like Cursor or Claude Code once chatting is no longer enough; by then you'll know what to teach it.
